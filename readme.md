# KeenKeeper

## 🚀 Features:

1. ### 🔔 Toast Notifications
   Toast notifications are used to provide feedback to the user after certain actions. The ToastContainer is placed in the root layout so that toast notifications can be accessed across different pages.
    
    layout.js ➡️ ToastContainer ➡️ All application routes


1. ### 📈 Activity Overview
   The visual data of total number of interactions. Users can quickly compare calls, texts, and video interactions through visual charts and summary cards. A pie chart is used to visualize the distribution of different interaction types(Call, Text, Video).

1. ### 🧑‍🤝‍🧑 Dynamic Friend Details
   Each friend has a dedicated dynamic route where their information is rendered
   ```
   /${id}
   ```

1. ### 📅 Timeline
   The timeline page briefly shows when and how often a friend is texted, called, or video-called .

1. ### 🔍 Filter Timeline
   A filter option is available for the timeline activities, allowing users to filter interactions by type:
   - 📞 Call
   - 💬 Text
   - 🎥 Video
